# Triade-OS
Triade OS - операционная система, написанная с нуля на Turbowarp (позже перейдет на C + NASM).

Данный репозиторий имеет все современные сборки ОС, начиная с Triade OS 12. Более ранние сборки возможно будут опубликованы на другом репозитории.

## Сборки
- современные сборки на Turbowarp - более 120 сборок
- версия C + NASM - в разработке
- версия на TRASM - скоро

## Расположение
- бета-версии - beta/
- релизы - realeses/

## Как запустить
1. скачай файл Triade OS
2. зайди на сайт turbowarp.org или установи Turbowarp Desktop для запуска файла
3. загрузи проект, нажав на файл => загрузить с компьютера
4. нажми на зеленый флаг, зайди в полноэкранный режим
